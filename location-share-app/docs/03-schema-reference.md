# Family Location Sharing App - Schema Reference (Reference)

## 1. SQLite Tables {#sqlite-tables}

### 1.1 members {#members}

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | TEXT | PRIMARY KEY | Unique member ID (from server/auth) |
| `display_name` | TEXT | NOT NULL | Human-readable name |
| `avatar_url` | TEXT | nullable | URL to avatar image (HTTP cached, not stored as blob) |
| `role` | TEXT | NOT NULL, DEFAULT 'member' | `'admin'` or `'member'` |
| `updated_at` | TEXT | NOT NULL | ISO 8601 UTC. Last time this row was updated locally |

### 1.2 locations {#locations}

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Local row ID |
| `member_id` | TEXT | NOT NULL, FK -> members(id) | Who this location belongs to |
| `lat` | REAL | NOT NULL | Latitude in decimal degrees |
| `lng` | REAL | NOT NULL | Longitude in decimal degrees |
| `accuracy` | REAL | NOT NULL | GPS accuracy in meters |
| `altitude` | REAL | nullable | Altitude in meters above sea level |
| `speed` | REAL | nullable | Speed in m/s |
| `bearing` | REAL | nullable | Bearing/heading in degrees (0-360) |
| `battery` | INTEGER | nullable | Battery percentage 0-100 |
| `timestamp` | TEXT | NOT NULL | ISO 8601 UTC. GPS-reported time of the fix |
| `source` | TEXT | NOT NULL | `'self'` = recorded by this device, `'remote'` = received from server |
| `synced` | INTEGER | NOT NULL, DEFAULT 0 | `0` = pending upload, `1` = uploaded. Only meaningful when `source = 'self'` |
| `created_at` | TEXT | NOT NULL, DEFAULT datetime('now') | When this row was inserted locally |

**Indexes:**

| Index | Columns | Condition | Purpose |
|-------|---------|-----------|---------|
| `idx_locations_member_time` | `member_id, timestamp` | none | History queries: all points for a member on a date |
| `idx_locations_synced` | `synced` | `WHERE source = 'self'` | Sync push: find unsynced own locations |
| `idx_locations_source` | `source, member_id, timestamp` | none | Latest-per-member queries filtered by source |

### 1.3 places {#places}

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | TEXT | PRIMARY KEY | UUID generated by server (or mock) |
| `name` | TEXT | NOT NULL | Display name (e.g. "Home", "School") |
| `lat` | REAL | NOT NULL | Center latitude |
| `lng` | REAL | NOT NULL | Center longitude |
| `radius_meters` | REAL | NOT NULL | Geofence radius in meters. Range: 50-2000 |
| `icon` | TEXT | NOT NULL, DEFAULT '📍' | Emoji or icon identifier |
| `created_by` | TEXT | NOT NULL, FK -> members(id) | Member who created this place |
| `created_at` | TEXT | NOT NULL | ISO 8601 UTC |
| `updated_at` | TEXT | NOT NULL | ISO 8601 UTC |

### 1.4 sync_meta {#sync_meta}

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `key` | TEXT | PRIMARY KEY | Metadata key name |
| `value` | TEXT | NOT NULL | Metadata value (always stored as text) |

**Known keys:**

| Key | Value Format | Description |
|-----|-------------|-------------|
| `last_pull_time` | ISO 8601 UTC | Last successful pull of family locations from server |
| `last_push_time` | ISO 8601 UTC | Last successful push of own locations to server |
| `device_id` | UUID string | Stable identifier for this device instance |

### 1.5 _migrations {#_migrations}

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `version` | INTEGER | PRIMARY KEY | Migration version number |
| `applied_at` | TEXT | NOT NULL, DEFAULT datetime('now') | When this migration was applied |

Created automatically by the migration runner. Not user-facing.

## 2. TypeScript Types {#typescript-types}

### 2.1 API Types (wire format) {#api-types}

These types define the shape of data exchanged with the server API. Defined in `$lib/api/types.ts`.

| Type | Usage | Key Fields |
|------|-------|------------|
| `LatLng` | Coordinate pair | `lat: number`, `lng: number` |
| `LocationReport` | Outbound: own location push | `memberId`, `lat`, `lng`, `accuracy`, `altitude?`, `speed?`, `bearing?`, `battery?`, `timestamp` |
| `MemberLocation` | Inbound: family member current location | All of `LocationReport` + `displayName`, `avatarUrl?`, `isOnline` |
| `Place` | Geofence definition (full) | `id`, `name`, `lat`, `lng`, `radiusMeters`, `icon`, `createdBy`, `createdAt` |
| `PlaceCreate` | Outbound: create a new place | `name`, `lat`, `lng`, `radiusMeters`, `icon` |
| `PlaceUpdate` | Outbound: partial update a place | All fields optional: `name?`, `lat?`, `lng?`, `radiusMeters?`, `icon?` |
| `HistoryQuery` | Inbound query param | `memberId`, `date` (YYYY-MM-DD) |
| `HistoryPoint` | Inbound: single history point | `lat`, `lng`, `accuracy`, `speed?`, `timestamp` |
| `FamilyGroup` | Inbound: family metadata | `id`, `name`, `members: FamilyMember[]` |
| `FamilyMember` | Inbound: member metadata | `id`, `displayName`, `avatarUrl?`, `role` |
| `LocationApi` | Interface contract | All API methods. See [Technical Spec, Section 3.1](./02-technical-spec.md#31-typescript-interface) |

### 2.2 DB Row Types (local storage format) {#db-row-types}

These types map 1:1 to SQLite table rows. Defined in `$lib/db/queries.ts`.

| Type | Maps To | Differences From API Type |
|------|---------|---------------------------|
| `MemberRow` | `members` table | Uses `snake_case` column names. No `isOnline` (derived from timestamp recency) |
| `LocationRow` | `locations` table | Has `id` (autoincrement), `source`, `synced`, `created_at` not in API types |
| `PlaceRow` | `places` table | Uses `snake_case`: `radius_meters`, `created_by`, `created_at`, `updated_at` |
| `SyncMetaRow` | `sync_meta` table | Simple `{ key: string, value: string }` |
| `MemberLocationRow` | JOIN result: latest location per member | Combines `members` + `locations` for UI display |

### 2.3 Store Types (reactive UI format) {#store-types}

Stores re-export API types directly where possible. Defined in `$lib/stores/*.svelte.ts`.

| Store | Exported State Type | Source |
|-------|-------------------|--------|
| `members.svelte.ts` | `MemberLocation[]` | `MemberLocationRow` mapped to `MemberLocation` |
| `places.svelte.ts` | `Place[]` | `PlaceRow` mapped to `Place` |
| `history.svelte.ts` | `HistoryPoint[]` | `LocationRow` mapped to `HistoryPoint` |
| `sync.svelte.ts` | `SyncState { online: boolean, pendingCount: number, lastSyncTime: string \| null }` | Derived from `sync_meta` + `navigator.onLine` + unsynced count query |

## 3. Type Mapping Rules {#type-mapping}

### 3.1 API <-> DB Column Mapping

| API Field | DB Column | Transform |
|-----------|-----------|-----------|
| `memberId` | `member_id` | camelCase <-> snake_case |
| `displayName` | `display_name` | camelCase <-> snake_case |
| `avatarUrl` | `avatar_url` | camelCase <-> snake_case |
| `radiusMeters` | `radius_meters` | camelCase <-> snake_case |
| `createdBy` | `created_by` | camelCase <-> snake_case |
| `createdAt` | `created_at` | camelCase <-> snake_case |
| `updatedAt` | `updated_at` | camelCase <-> snake_case |
| `isOnline` | (derived) | `true` if `timestamp` is within 5 minutes of now |
| `battery` | `battery` | Same (integer 0-100 or null) |
| `timestamp` | `timestamp` | Same (ISO 8601 UTC string) |

### 3.2 Naming Conventions

| Context | Convention | Example |
|---------|-----------|---------|
| SQLite columns | `snake_case` | `member_id`, `created_at` |
| TypeScript API types | `camelCase` | `memberId`, `createdAt` |
| TypeScript DB row types | `snake_case` (match DB) | `member_id`, `created_at` |
| Svelte component props | `camelCase` | `memberId`, `isOnline` |
| CSS classes | `kebab-case` | `member-card`, `sync-badge` |
| File names | `kebab-case` for components, `camelCase` for modules | `MemberCard.svelte`, `queries.ts` |

### 3.3 Timestamp Convention

All timestamps are ISO 8601 UTC strings: `YYYY-MM-DDTHH:mm:ss.sssZ`

| Context | Format | Example |
|---------|--------|---------|
| GPS timestamp | ISO 8601 UTC | `2026-03-08T10:30:00.000Z` |
| DB storage | ISO 8601 UTC (TEXT column) | `2026-03-08T10:30:00.000Z` |
| API wire format | ISO 8601 UTC | `2026-03-08T10:30:00.000Z` |
| UI display | Locale-formatted via `toLocaleTimeString()` | `9:30:00 PM` |
| History date query | `YYYY-MM-DD` (date only) | `2026-03-08` |

### 3.4 ID Conventions

| Entity | Format | Generated By |
|--------|--------|-------------|
| Member ID | UUID v4 string | Server (Keycloak subject ID) |
| Location ID | Auto-increment integer | SQLite |
| Place ID | UUID v4 string | Server (or `crypto.randomUUID()` in mock) |
| Device ID | UUID v4 string | Generated once on first app launch, stored in `sync_meta` |

## 4. Value Constraints {#constraints}

| Field | Type | Min | Max | Unit | Notes |
|-------|------|-----|-----|------|-------|
| `lat` | REAL | -90 | 90 | degrees | WGS 84 |
| `lng` | REAL | -180 | 180 | degrees | WGS 84 |
| `accuracy` | REAL | 0 | 1000 | meters | GPS accuracy radius |
| `altitude` | REAL | -500 | 100000 | meters | Above sea level |
| `speed` | REAL | 0 | 1000 | m/s | Ground speed |
| `bearing` | REAL | 0 | 360 | degrees | Clockwise from north |
| `battery` | INTEGER | 0 | 100 | percent | Device battery level |
| `radius_meters` | REAL | 50 | 2000 | meters | Geofence radius |
| `role` | TEXT | — | — | — | Enum: `'admin'`, `'member'` |
| `source` | TEXT | — | — | — | Enum: `'self'`, `'remote'` |
| `synced` | INTEGER | 0 | 1 | — | Boolean: `0` = false, `1` = true |
